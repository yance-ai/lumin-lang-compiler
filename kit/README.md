# Lumin Kit

Lumin 开发套件，包含可独立分发的子项目。

## 子项目

- `runtime/` — 语言运行时（已完成）
  - 内存管理（GC）
  - 基础类型（Value/字符串/数组/Map）
  - 线程/锁/TLS
  - IO/HTTP/JSON/正则/时间/字符集/加密
- `ui/` — UI 框架（开发中，占位）

## 设计原则

1. **零依赖编译器** — kit/ 下的子项目不能 include src/ 下的任何头文件
2. **独立构建** — 每个子项目有自己的 include/ 和 src/，可单独编译为静态库
3. **API 稳定** — include/ 下的头文件是公开 API，src/ 是内部实现
4. **未来可拆出** — API 稳定后，整个目录可移到独立仓库
